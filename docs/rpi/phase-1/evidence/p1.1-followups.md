Now all evidence goes through `scripts/save-output.mjs <file> -- <cmd…>`, which exits with the command's code (1 on a signal, 127 if the command is missing), appends `exit: <code>`, and redacts secret-shaped values. `arbiter/test/save-output.test.mjs`: a failing command, a failing `node --test` run, a killed command, a missing command, redaction. CLAUDE.md says to use it. |

Finding while testing: a `node --test` started inside a `node --test` process inherits `NODE_TEST_CONTEXT`, reports to the parent and exits 0 even when its tests fail. The test clears it. This only matters for nested test runs, not for evidence runs from a shell.
