## What changed

- `arbiter/src/errors.js`: registry of 17 codes, each with one status and a meaning. `ArbiterError(code, message, {reason, headers})` takes its status from the registry and refuses an unknown code. The 18 status arguments at call sites are gone. The one call that disagreed (`invalid` with 500, for a missing `buyerKey`, a caller bug) is now a plain `Error`, so it surfaces as `internal`. `/mcp` GET and the unknown route now throw registry codes (`method_not_allowed`, `not_found`).
- `arbiter/src/log.js` and the `fetch` wrapper: one `console.log` object per request (`ts, level, request_id, env, version, method, route, status, code, duration_ms`), plus `mcp` (allow-listed method and tool names, with the code), `reason` (fixed words on `misconfigured`), and `error_class` and `error_fingerprint` (a hash of stack function names) on `internal`. `route` is a template. Every response gets `x-request-id` (cf-ray when it looks like one, else 16 random bytes in hex), which is added to CORS `Expose-Headers`. Every error body is `{error, message, request_id}`: the Oja client still sees `{error, message}`.
- The two `console.error` calls in `core.js` are gone. Their information is now `reason` on the request's line.
- `wrangler.toml`: `[observability] enabled = true`, `head_sampling_rate = 1`, and `ENVIRONMENT` set per environment (vars are not inherited). Each block is repeated per environment, as the Workers Logs docs do.
- **`invocation_logs = false`** in all environments. Cloudflare's invocation logs record "the Request, Response, and related metadata", and the limits page counts "request metadata, and headers" in a request's log data. No page says whether `Authorization` (buyer, vendor and admin tokens) or the caller IP is left out, so they are off. **P1.8 item:** on staging, confirm in the dashboard what Workers Logs stores for a request.
- README "Error codes" table (generated from the registry, test-checked). Runbook `## Logs` (`wrangler tail --env X --format json`, which exists in wrangler 4.166.0 `tail --help`).
