- `GET /accounts/:id/workers/subdomain` → error 10007 "You do not have a workers.dev subdomain". The account has no workers.dev subdomain at all.
- `GET /accounts/:id/workers/scripts/open-arbiter-staging/subdomain` → `{"enabled": false, "previews_enabled": false}`.
- `GET /zones` → 0 zones, so no route can point at it.

So the stub can't be reached from the internet. **For A2:** the first `deploy --env staging` (`workers_dev = true`) needs a workers.dev subdomain on the account, and its name becomes part of the public URL (`open-arbiter-staging.<subdomain>.workers.dev`). Creating it is an account-level choice for the owner.
