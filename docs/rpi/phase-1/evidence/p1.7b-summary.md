# P1.7b: daily negotiation cap as an environment setting (carrier NAT): evidence (2026-11-27)

Owner decision, 2026-11-27. Many Nigerian mobile users share one public IP. The leak bound in mechanism 3.0.0 already holds for any number of deals, so the per-IP cap is load protection, not price protection. It becomes an environment setting, 20 per item per IP in staging and production, with the identical-terms lock unchanged. Local only.

The property test covers 400 sellers × 20 deals (the deployed cap, imported from the code) at random quantities 1–12. 80% of the budgets bisect the floors still possible, and 20% are random within them. After every sequence at least one `unit_step` of floors remains, and more than half are pinned to under 2 steps.

## What changed

- `core.js`: `MANDATE_CAP_DEFAULT = 20`, and an Arbiter option `mandateCap`. The conditional insert is the same one, so it is still enforced by the database. The 429 message now says the cap limits load and that prices reveal at most one step. It no longer says "stops repeated bids from mapping a seller's floor".
- `mechanism.js`: `mandatesPerBuyerPerSkuPerDay` is removed from `LIMITS`. It was never pricing; pricing and `MECHANISM` 3.0.0 are unchanged.
- `quota.js`: `mandateCap(env)` reads `MANDATES_PER_ITEM_PER_DAY` (integer 1–1000; any other value falls back to 20). `wrangler.toml` sets `"20"` at the top level and in staging and production, and a test checks each.
- `GET /` publishes `limits: { negotiations_per_item_per_day, requests_per_ip_per_minute, catalog_page_max }`. `concurrency.mjs` F2 reads the cap from it and sends cap + 5 concurrent creates.
- **The identical-terms lock is unchanged.** `mandate-cap.test.mjs` checks it far below the cap, and the existing identical-terms and idempotency tests are unchanged and pass.
- The tests that hard-coded 3 (`antiprobing`, `core`, `idempotent-mandate`) now use `MANDATE_CAP_DEFAULT`.
- ADR 0001 has an amendment, "The daily cap", and a property-table row. The multi-deal caveat no longer credits the cap.
- README feature list and Limits, the error table, CLAUDE.md invariant 3, and Oja's `negotiate` action description ("3 negotiations per day" became "a limited number … (20 by default)").
- `docs/production-plan.md` P6.5: evaluate Cloudflare Turnstile on negotiate and accept against distributed abuse, with a non-JavaScript fallback for agents.
