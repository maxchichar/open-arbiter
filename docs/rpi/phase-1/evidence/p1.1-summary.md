Fixed: cleanup is in `finally`, and `.gitignore` now lists `*.jwk`, `*.pem` and `dist/`. The secret scan refuses `*.jwk` files.

**Second finding (caught by the new secret scan):** in the same red run the old keygen ignored `--out` and printed a private JWK, which the saved test output `p1.1-red.txt` captured. The scan flagged it once the evidence was staged. The private scalar is redacted in that file (the public `x`/`y` are left), and the unpushed commit was amended. That key was never used or set anywhere. The scan also skips its own file, whose fixtures are fake secrets.
