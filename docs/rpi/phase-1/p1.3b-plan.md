## 3. Design

**D1: Trusted Types in the page CSP.** Append `; require-trusted-types-for 'script'; trusted-types agentify-website` to the four page policies. Why it's safe: upstream routes every runtime sink through the policy, Oja's own code has none, browsers without Trusted Types ignore both directives, and a page that refuses the policy name gets plain strings. In that last case the sink throws and the browser reports a violation, so `browser_check.py` fails loudly instead of breaking quietly. What we gain: a future DOM-XSS sink, in the runtime or our code, fails closed. **Bridge (`/bridge/*`): unchanged in this slice.** No browser test loads the bridge yet (peer policy closed), and invariant 13 says don't change a directive without a test. It gets Trusted Types with the seller-storefront slice, which exercises the bridge in a browser.

**D2: bridge callers.**
```js
static CALLERS = [];            // exact origins only, never "*"; seller storefronts add theirs
static EVERY_SITE = ["*"];      // only for reads the owner confirmed return only public-page facts
get_market_state → EVERY_SITE   // the catalogue is what the public page shows
verify_receipt   → owner decision D-3b.2
```
Oja's test pins the confirmed set as `EVERY_SITE_READS = ["get_market_state", …]`. Changing which reads go to every site then takes a code change and a test change that a reviewer sees together.

**Diagram: what changes at the browser boundary**
```
page (Oja origin) ── CSP: script-src 'self' + require-trusted-types-for 'script'
  runtime/ui.js ──trustedHtml()──▶ innerHTML           (policy "agentify-website", once)
  runtime/sandbox.js ──trustedScriptUrl()──▶ new Worker(runtime/sandbox-worker.js)  (own CSP, unchanged)
  js/*, site*.js ── DOM APIs only (no sinks; R3 enforces)
bridge frame (other sites) ── CALLERS (exact) | EVERY_SITE (confirmed reads) ── no writes shared
```

**Alternatives.** (a) Re-pin without turning on Trusted Types: a smaller change, but it gives up the hardening the upstream change exists for. Kept as the fallback if D1 shows a violation we can't remove without editing the runtime. (b) Re-pin to tag `0.2.2`: it lacks Trusted Types and the bridge rules, so rejected. (c) Edit our runtime copy (now allowed upstream): rejected by invariant 6.
